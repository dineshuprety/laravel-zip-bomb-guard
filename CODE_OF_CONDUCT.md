# Code of Conduct

This project welcomes contributors with different backgrounds and levels of experience. Treat other participants with respect in issues, pull requests, reviews, and other project spaces.

## Expected behavior

- Discuss the code and its behavior; avoid personal attacks.
- Give concrete, constructive feedback and accept corrections in good faith.
- Respect people's time, privacy, and boundaries.
- Keep discussions relevant and make room for questions from new contributors.

Harassment, discriminatory abuse, threats, unwanted sexual attention, doxxing, and repeated disruptive behavior are not acceptable. Do not publish another person's private information without their permission.

## Reporting and moderation

Report conduct concerns privately to **codewithdinesh@gmail.com**. Include links, relevant context, and any immediate concern. Share only the personal information needed to understand the report. Security vulnerabilities belong in the separate [security reporting process](SECURITY.md).

Maintainers may request changes, remove content, close disruptive discussions, or restrict participation. The response should reflect the severity and context of the behavior. Reports should be handled discreetly, with details shared only as needed to investigate or respond; absolute confidentiality cannot be guaranteed.

This policy applies to project spaces and to public interactions where someone represents the project.
